# 🎬 Checkpoint 5 — Domain Driven Design (Java)

Sistema de gerenciamento de filmes desenvolvido em **Java** com arquitetura **MVC** e padrão **DAO/DTO**, integrado ao banco de dados **Oracle** via **JDBC**. Projeto acadêmico da disciplina *Domain Driven Design - Java* da FIAP.

## 🗄️ Banco de dados

Execute o script abaixo no Oracle (SQL Developer) antes de rodar o projeto:

```sql
CREATE TABLE ddd_filme (
    codigo NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    titulo VARCHAR2(35),
    genero VARCHAR2(10),
    produtora VARCHAR2(15)
);
```

## ▶️ Como executar

1. Importe o projeto no IntelliJ IDEA (JDK 25).
2. Adicione o driver `ojdbc17.jar` (pasta `lib`) às dependências do projeto.
3. No arquivo `ConnectionFactory.java`, preencha **USUARIO** e **SENHA** do seu banco Oracle:

```java
final String USER = "seu_usuario";
final String PASS = "sua_senha";
```

4. Rode a classe `br.com.fiap.view.FilmeView` (contém o `main`).

## ✅ Funcionalidades (CRUD)

- **Inserir** filme
- **Alterar** filme
- **Excluir** filme
- **Listar** filmes

Os dados são solicitados via **console (Scanner)**; apenas a opção **Listar** exibe o resultado em uma janela gráfica (`JOptionPane`).

## 📚 Conceitos aplicados

- Programação Orientada a Objetos (encapsulamento)
- Arquitetura MVC (Model, View, Controller)
- Padrão DAO (Data Access Object) e DTO
- Conexão com banco via `ConnectionFactory`
- `PreparedStatement` com `try-with-resources`
- Coleções (`ArrayList`) e `String.format()`
